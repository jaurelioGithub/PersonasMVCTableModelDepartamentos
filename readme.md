PersonasMVCTableModelDepartamentosBD
===========

Descripcion
-----------
Sistema de registro de Personal. Estructura de capas: presentacion, lógica y datos.  Aplica el Model-View-Controller (MVC) en la capa de presentación.
Usa un Jtable asociado a un TableModel para desplegar la lista.
Usa una librería JDBC para persistencia en BD.
Establece la relación entre Persona y Departamento y EsadoCivil
