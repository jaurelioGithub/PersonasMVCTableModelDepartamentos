PersonasMVCTableModelDepartamentosXML
===========

Descripcion
-----------
Sistema de registro de Personas. Estructura de capas: presentacion, lógica y datos.  Aplica el Model-View-Controller (MVC) en la capa de presentación.
Usa un Jtable asociado a un TableModel para desplegar la lista.
Usa la librería JAXB para persistencia en XML.
Establece la relación entre Persona y Departamento
